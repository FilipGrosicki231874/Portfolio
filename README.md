# Portfolio

A dark, minimalist portfolio website built with HTML and CSS.

## Files

- `index.html` — page structure and content
- `style.css` — styling and responsive layout

## Getting started

1. Replace the placeholder text in `index.html`.
2. Replace the placeholder image URLs with your own images.
3. Replace `Github link` and `LinkedIn link` with your actual URLs.
4. Replace the email and phone number.
5. Push the files to your GitHub repository.
6. Enable GitHub Pages in the repository settings.

## Replacing images

You can create an `images` folder and use paths such as:

```html
<img src="images/profile.jpg" alt="Name">
```

For project images:

```html
<img src="images/project-one.jpg" alt="Screenshot of Project One">
```

## Contact form

GitHub Pages is static hosting, so the form does not process submissions on its own.
Connect the form to a form service when you're ready, or change it to a mailto-based contact method.
